# Жимовая прога — приложение для телефона

Программа тренировок «Жимовая прога v 2.0» в виде устанавливаемого веб-приложения (PWA):
план на 2 подготовительные недели, тестовую неделю и 12 недель, расчёт рабочих весов по RPE,
журнал, прогресс, калькулятор разминки. Работает офлайн, без регистрации и без сервера.

* Аудит исходной книги и найденные ошибки — [docs/WORKBOOK_AUDIT.md](docs/WORKBOOK_AUDIT.md)
* Все формулы и коэффициенты — [docs/FORMULA_MAP.md](docs/FORMULA_MAP.md)
* Исходный файл не изменялся; копия — `source/Жимовая прога v 2.0 (backup).xlsx`

## Что умеет

| Раздел | Что внутри |
|---|---|
| **Сегодня** | Следующая тренировка, этап программы, что ещё нужно заполнить, вес тела |
| **Тренировка** | Плановые подходы рядом с фактическими; ввод веса и повторений с кнопками − / + (шаг упражнения), RPE в один тап, отметка подхода; подсказка «прошлый раз» (подставляется только по кнопке); таймер отдыха (пропустить / заново / ±15 с, вибрация); заметки; добавить подход; заменить упражнение |
| **План** | Все недели и три дня, плановые веса; любую будущую группу подходов можно изменить (вес, подходы, повторения) или вернуть к расчёту |
| **История** | Завершённые тренировки: план на момент тренировки и факт; фильтр по упражнению; правка факта |
| **Прогресс** | Оценочный 1ПМ, вес тяжёлого подхода, тоннаж, сравнение по датам, рекорды по повторениям, объём по мышцам, вес тела |
| **Ещё** | Калькулятор подходов (жим, становая), выбор упражнений и шагов округления, тестовые результаты, шкала RPE, настройки и резервная копия |

Тёмная тема по умолчанию, переключатель светлой — на главном экране и в настройках.

### Как работает расчёт (коротко)

1. **Подготовка** (2 недели): в первом подходе вы сами подбираете вес по условию («6–8ПМ, RPE 7–9»),
   отмечаете повторения и RPE — следующие подходы рассчитываются.
2. **Тест**: один подход до отказа на 3–6 повторений. Результаты сохраняются при завершении тренировки
   (поправить — «Ещё → Тестовые результаты»).
3. **12 недель**: вес тяжёлого подхода недели считается от теста или от тяжёлого подхода прошлой недели и его RPE.
   Подсобные подходы пересчитываются сразу, как только вы отметили RPE тяжёлого. Без RPE следующий вес
   не выдумывается: в плане будет «ждёт RPE» с указанием, где его отметить.

### Собственный вес и отягощения

* Вес тела вводится **один раз** (главный экран или настройки) и меняется, только когда меняется ваш вес.
  История веса хранится по датам.
* **Подтягивания с отягощением**: в тренировке вводите только **навешенный вес** (например, 12,5).
  Программа сама прибавляет вес тела для расчёта и показывает «всего 92,5 кг». Отрицательное число — помощь (резинка/гравитрон).
* **Подтягивания с собственным весом**: только повторения, вес не нужен.
* Каждая тренировка запоминает вес тела на свой день: новый вес тела меняет будущие расчёты, но не прошлые записи.

### Персональные замены

* Вместо отжиманий на брусьях — **жим-сжимание гантелей лёжа на наклонной скамье 30°** (вес одной гантели, тоннаж ×2,
  свой тест, своя история, свой шаг и выбор «рабочего диапазона»).
* Вместо подъёма штанги на бицепс — **сгибания рук на тренажёре Скотта** (бицепс, не спина; своя история).

## Запуск на компьютере

Нужен Node.js 20+.

```bash
npm install
```

```bash
npm run dev
```

Откройте адрес из консоли (обычно http://localhost:5173). Проверка на телефоне в той же Wi-Fi-сети:
`npm run dev -- --host`, затем на телефоне — адрес вида `http://192.168.x.x:5173`
(для установки на главный экран нужен HTTPS — см. ниже).

Тесты и сборка:

```bash
npm test
```

```bash
npm run build
```

Готовые статические файлы — в `dist/`. Посмотреть собранную версию локально:

```bash
npm run preview
```

> `dist/index.html`, открытый двойным щелчком с диска, **не** будет полноценным приложением:
> service worker и установка работают только по HTTPS или на localhost.

## Публикация на HTTPS (бесплатно)

Сборка использует относительные пути (`base: './'`), поэтому работает из любой папки хостинга.

### Вариант 1. GitHub Pages

1. Создайте репозиторий на GitHub и загрузите в него папку проекта (без `node_modules` и `dist`).
2. Локально выполните `npm run build`.
3. Создайте ветку `gh-pages` с содержимым `dist/`, например:
   ```bash
   npx gh-pages -d dist
   ```
4. GitHub → Settings → Pages → Source: ветка `gh-pages`, папка `/ (root)`.
5. Через минуту приложение будет доступно по адресу `https://<логин>.github.io/<репозиторий>/`.

### Вариант 2. Netlify Drop (без Git)

1. `npm run build`.
2. Откройте https://app.netlify.com/drop и перетащите папку `dist`.
3. Получите адрес `https://<имя>.netlify.app` (HTTPS включён автоматически).

Подходит любой статический хостинг с HTTPS (Cloudflare Pages, Vercel, свой сервер).
Отдельная настройка сервера не нужна: приложение использует адреса вида `#/plan`.

## Установка на телефон

Откройте опубликованный HTTPS-адрес один раз (с интернетом), затем:

* **Android (Chrome)**: меню ⋮ → «Установить приложение» / «Добавить на главный экран».
* **iPhone (Safari)**: кнопка «Поделиться» → «На экран „Домой“».

После первого открытия приложение работает **без интернета**. Когда выходит новая версия,
приложение предложит обновиться; данные при этом сохраняются.

## Данные, резервная копия и синхронизация

* Все данные хранятся **только в этом браузере на этом устройстве** (IndexedDB). Сервера и аккаунта нет,
  никакие данные никуда не отправляются.
* **Автоматической синхронизации между телефоном и компьютером нет.** Для переноса:
  «Ещё → Настройки → Сохранить копию (JSON)» на одном устройстве и «Восстановить из копии…» на другом.
  Восстановление заменяет данные целиком и запрашивает подтверждение; повреждённый или чужой файл отклоняется с объяснением.
* Делайте копию регулярно: при очистке данных браузера или удалении приложения с телефона журнал будет потерян.
  Приложение просит браузер не удалять базу автоматически, но гарантию дают только копии.
* «Журнал в CSV» — для Excel (разделитель «;», десятичная запятая): дата, неделя, упражнение, исходное название, план, факт, RPE, тоннаж.
* Схема хранения версионирована (`SCHEMA_VERSION`), импорт старых копий проходит через миграции.

## Структура проекта

```
src/domain/calculations/  таблица RPE, округление, 1ПМ (таблица RPE, Бжицки), калькулятор подходов
src/domain/program/       структура программы (слоты, варианты, правила недель), движок плана,
                          таблицы «Формул» (workbook.generated.json — извлечены скриптом)
src/domain/exercises/     каталог упражнений и типов нагрузки
src/domain/progression/   связь журнала и плана, аналитика, построение тренировки
src/storage/              IndexedDB (Dexie), операции, резервная копия и CSV
src/ui/                   экраны и компоненты (React)
scripts/                  извлечение формул из книги, эталон через Excel, генерация иконок
tests/                    Vitest: расчёты, движок, сверка с Excel, хранение, экраны
docs/                     аудит книги, карта формул, полные тексты формул
```

Пересоздать данные из книги (только чтение исходника):

```bash
python scripts/extract_workbook.py "Жимовая прога v 2.0.xlsx"
```

Эталон Excel (Windows + Excel + pywin32; книга копируется во временную папку):

```bash
python scripts/excel_golden.py
```

## Ограничения

* Нет синхронизации между устройствами (только через файл копии).
* Допущения там, где книга молчит или ошибается (недели 4/8/12 для строк «+», становая 250–300 кг в калькуляторе и др.),
  перечислены в конце [аудита](docs/WORKBOOK_AUDIT.md#7-открытые-допущения-редактируемы-в-приложении) и помечены в интерфейсе.
* Ссылки на платные видео-гайды из книги в приложение не перенесены.
