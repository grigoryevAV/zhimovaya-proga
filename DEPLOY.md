## Как обновить сайт после изменений

1. Собрать свежую папку `dist/` в этом проекте. Сборка — под Windows; в WSL не собирать (там нет установленных под Windows `node_modules`).
2. Заменить содержимое ветки `gh-pages` новой сборкой: в локальной копии репозитория (`/home/alex/zhimovaya-proga`) переключиться на ветку `gh-pages`, удалить из неё файлы старой сборки, скопировать туда всё содержимое нового `dist/`, убедиться, что в корне остался пустой файл `.nojekyll`, затем `git add -A`, `git commit`, `git push`.
3. GitHub Pages пересоберёт сайт автоматически — обычно в течение 1–3 минут после пуша.
