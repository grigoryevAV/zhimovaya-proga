# Карта расчётов

Все расчёты — чистые функции в `src/domain/`. Обозначения: `MR(x, s)` — округление к ближайшему
кратному шага `s` (Excel `MROUND`, половина — вверх); `C(RPE, n)` — коэффициент из матрицы RPE;
`Бж(w, n) = w / (1.0278 − 0.0278·n)` — формула Бжицки. Примеры с числами взяты из пересчёта
книги в Excel (`tests/fixtures/excel-golden.json`, сценарий A) — приложение даёт те же значения.

## 1. Матрица RPE — `calculations/rpeTable.ts`

* Источник: «Формулы»!N92:X100 (дублируется на листе программы AC79:AM87).
* Вход: RPE ∈ {6,5; 7; …; 10}, повторения 1–10 (целые).
* Выход: доля 1ПМ. `C(10,1) = 1`, `C(8,5) = 0,81`, `C(6,5,10) = 0,64`.
* Пусто → «Не указан RPE»; RPE 0, 6, 8,3, 10,5 → «вне шкалы»; повторения 0, 11, 2,5 → «таблица покрывает 1–10».
  В книге всё это — `#N/A`.
* Тест: `calculations.test.ts › таблица RPE` (все 80 пар, монотонность, недопустимые значения).

## 2. Оценка 1ПМ — `calculations/oneRm.ts`

| Функция | Формула | Где в книге | Область | Пример |
|---|---|---|---|---|
| `e1rmFromRpe(w, n, rpe)` | `w / C(rpe, n)` | все `INDEX/MATCH` листа «Формулы» | n 1–10, RPE 6,5–10, w > 0 | 80 × 6 @10 → 95,24 |
| `brzycki(w, n)` | `w / (1.0278 − 0.0278·n)` | Программа!AF:AN (недели 4/8/12) | **1 ≤ n ≤ 15** (в книге без ограничения; при n ≥ 37 знаменатель ≤ 0) | 90 × 3 → 95,30 |
| `brzyckiRir(w, n, rpe)` | `Бж(w, n + 10 − rpe)` | AF154, Y162, AC162, AJ208… | то же для n + запас | 90 × 3 @7,5 → Бж(90; 5,5) = 102,9 |

## 3. Округление — `calculations/rounding.ts`

* `mround` — к ближайшему, половина вверх: 71,24 → 70; 71,25 → 72,5 (шаг 2,5); 13 → 14 (шаг 2); 4,5 → 6 (шаг 3); 7,5 → 10 (шаг 5).
* `ceilingStep`/`floorStep` — только в калькуляторе подходов (как в книге).
* Хвосты двоичной арифметики гасятся (`72,49999999 → 72,5`). Шаг ≤ 0 → ошибка, а не Infinity.
* Шаги в списке книги: 1, 2, 2,5, 3, 5 кг (`Коэффициенты!O18:O22`); в приложении можно задать свой.
* **Шаг привязан к упражнению**, а не к слоту (книга: к слоту, с ошибками № 6, 8 аудита).
* Для отягощений округляется **навешенный** вес: `MR(raw − вес тела, шаг)`.

## 4. Подготовительный период — `program/engine.ts › prepDefs`

Источник: «Программа»!F77:W97. Каждый «подход» — отдельная группа из 1 подхода с вводом RPE.

```
П1 подход 1: вес и повторения выбирает пользователь (условие слота, напр. «6–8ПМ, RPE 7–9»)
П1 подход 2 = MR( П1п1.вес / C(П1п1.RPE, П1п1.повт) × k₁ , шаг )   повторения r₁
П1 подход 3 = MR( П1п2.вес / C(П1п2.RPE, r₁)        × k₂ , шаг )   r₂
П2 подход 1 = MR( П1п1.вес / C(П1п1.RPE, П1п1.повт) × k₃ , шаг )   r₃
П2 подход 2 = MR( П2п1.вес / C(П2п1.RPE, r₃)        × k₄ , шаг )   r₄
П2 подход 3 = MR( П2п2.вес / C(П2п2.RPE, r₄)        × k₅ , шаг )   r₅
```

| Слот | Условие подхода 1 | k₁…k₅ | r₁…r₅ |
|---|---|---|---|
| Д1 жим, Д1 вертикальная тяга | 6–8ПМ | 0,8; 0,8; 0,82; 0,8; 0,78 | 5, 5, 4, 5, 6 |
| Д1 ноги | 8–10ПМ | то же | то же |
| Д1 дельты | 10–12ПМ | 0,72; 0,72; 0,72; 0,72; 0,69 | 8, 8, 6, 8, 10 |
| Д2 жим | 8–10ПМ | 0,8; 0,8; 0,82; 0,8; 0,78 | 5, 5, 4, 5, 6 |
| Д2 тяга, Д2 бицепс | 6–8ПМ | то же | то же |
| Д2 трицепс, Д2 «+», Д3 спина, Д3 «+» | 10–12ПМ | 0,72; 0,72; 0,72; 0,72; 0,69 | 8, 8, 6, 8, 10 |
| Д3 ноги, Д3 жим вверх | 6–8ПМ | 0,8; 0,8; 0,82; 0,8; 0,8 | 5, 5, 4, 5, 5 |
| Д3 горизонтальная тяга | 8–10ПМ | то же | то же |

Собственный вес: Д1 «+» (строка 81) — повторения цепочкой `следующий = MR(пред. + (10 − RPE − d), 1)`,
d = 3, 2, 2, 1, 1; брусья/подтягивания (строки 88, 96) — повторения-константы r₁…r₅, без веса.

Пример (жим, Excel F77:L77): подход 1 — 75 × 6 @9 → подход 2 = MR(75 / C(9;6)=0,81 × 0,8; 2,5) = 74,1 → **75** (I77);
подход 2 выполнен 75 × 5 @9 → подход 3 = MR(75 / C(9;5)=0,84 × 0,8) = 71,4 → **72,5** (L77).

## 5. Недели 1–3, 5–7, 9–11 — `program/engine.ts › blockDefs`

Источник: «Формулы»!Q:CA, 9 блоков по 7 столбцов на строку-упражнение. Коэффициенты всех строк —
в приложении A (сгенерировано из книги).

```
Тяжёлые, неделя 1:   MR( тест.вес / C(10, тест.повт) × k_top , шаг )        ← «тест до отказа» = RPE 10
Тяжёлые, неделя N:   MR( Т(N−1).вес / C(Т(N−1).RPE, Т(N−1).повт) × k_top , шаг )   N−1: 5←3, 9←7
Подсобные, неделя N: MR( Т(N).вес   / C(Т(N).RPE,   Т(N).повт)   × k_back, шаг )   — после RPE тяжёлого
```

* `Т(N).RPE` — RPE первого выполненного тяжёлого подхода недели (ввод пользователя, книга: столбцы F/M/T).
* `Т(N).вес/повт` — фактические, если записаны, иначе плановые (в книге — всегда плановые).
* Подходы тяжёлых: число или «1, если то же упражнение выбрано в другом дне, иначе 3» (присед Д3, ягодичный мост Д3, наклонный жим Д1).
* Подсобные «до отказа» — у изолирующих и гантельных схем.
* Пример (жим Д1, Excel): тест 80 × 6 → неделя 1: 80 / C(10;6)=0,84 × 0,837 = 79,7 → **80** (C154).
  RPE 8 → подсобные: 80 / C(8;3)=0,86 × 0,739 = 68,7 → **67,5** (G154); неделя 2: 80 / 0,86 × 0,85 = 79,1 → **80** (J154).
  RPE недели 2 = 8,5 → неделя 3: 80 / C(8,5;3)=0,88 × 0,863 = 78,5 → **77,5** (Q154).

Если упражнение в слоте сменилось, цепочка начинается заново от теста нового упражнения (`restartFromTest`).

## 6. Собственный вес — повторения

Источник: строки 14, 37, 59, 68, 69 «Формул».

```
Контрольный подход, неделя 1:  тест.повт − 2
Контрольный подход, неделя N:  ⌊10 − RPE(N−1) + повт(N−1) − d_top⌋
Рабочие подходы, неделя N:     ⌊10 − RPE(N) + повт(N) − d_back⌋    ← в неделе 11 книга берёт неделю 10 (исправлено)
Недели 4/8/12:                 тест.повт − 4 / −3 / −3  (4, 3, 3 подхода)
```

Пример (подтягивания Д3, Excel): тест 10 → неделя 1 = **8** (E173); RPE 9 → рабочие ⌊10 − 9 + 8 − 3⌋ = **6** (I173), неделя 2 ⌊10 − 9 + 8 − 1⌋ = **8** (L173).
Результат < 1 показывается как 1 с пометкой «проверьте RPE».

## 9. Тест и общие тесты — `engine.ts › resolveTest`

* Тест = вес × повторения @RPE (по умолчанию 10, «до отказа»). Отягощение — навешенный вес + вес тела на дату теста.
* Если упражнение выбрано в двух днях: недели 1–3, 5–7, 9–11 — тест первого дня (Д1 жим → Д2 жим,
  Д1 ноги → Д3 ноги, Д2 тяга/таз → Д3 ноги (ягодичный мост), Д1 подтягивания → Д3 подтягивания);
  недели 4/8/12 — свой тест, при его отсутствии — общий.
* Тест другого упражнения (например, брусьев для жима-сжимания) **не используется**: «нужен тест».

## 10. Подтягивания с отягощением — `engine.ts › finalizeLoad`, `fromLogs.ts › setLoad`

```
вес тела  — из профиля (одна запись, меняется при изменении веса, хранится история по датам)
ввод      — только навешенный вес
расчёт    — полный вес = вес тела + навешенный; 1ПМ и коэффициенты — от полного
план      — навешенный = MR(полный_расчётный − вес тела, шаг); отрицательный = помощь
тоннаж    — (вес тела + навешенный) × повторения; вес тела — снимок на дату тренировки
```

Пример: вес тела 80, тест +20 × 5 → полный 100 → неделя 1: 100 / 0,86 × 0,83 = 96,5 → навешенный MR(16,5; 2,5) = **+17,5 кг** (Excel C155 = 100 при тесте 110 × 3 — тот же принцип).
Смена веса тела на 85 → **+12,5 кг** (полный вес тот же). Без веса тела — «Укажите вес тела», а не 0.

## 11. Гантели

Вес вводится на одну гантель, шаг — на одну гантель, расчёт 1ПМ — на одну гантель (коэффициенты
относительные), тоннаж = вес × 2 × повторения. В интерфейсе: «2 × 16 кг = 32 кг».

## 13. Журнал и аналитика — `progression/*.ts`

| Показатель | Расчёт |
|---|---|
| Опорное значение группы | первый выполненный подход группы с RPE (для AMRAP — с повторениями); учитываются и незавершённые тренировки, поэтому подсобные пересчитываются сразу |
| Оценочный 1ПМ подхода | `w / C(RPE, n)` при n ≤ 10; AMRAP без RPE = RPE 10; 11–15 повторений до отказа — Бжицки; без RPE — нет оценки |
| Тоннаж | Σ вес × повт.; гантели ×2; собственный вес и отягощения — с весом тела на дату тренировки |
| Объём по мышцам | подходы: основная мышца — 1, вспомогательные — 0,5; отдельно — подходы с осевой нагрузкой |
| Рекорды | лучший оценочный 1ПМ, лучший вес для каждого числа повторений, максимум повторений |

Сгибания на тренажёре Скотта: основная мышца — бицепс, вспомогательных нет, осевой нагрузки нет.
