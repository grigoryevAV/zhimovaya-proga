# Режим дня и питание в «Жимовой проге» — спецификация

Дата: 22.10.2026. Статус: на согласовании у пользователя.
Источники: `nedelnyy-grafik.md` (главный), `rezhim_1.html` (утренняя прогулка 09:35–09:50).

## 1. Цель и решения пользователя

Всё в одном приложении: силовые («Жимовая прога»), режим дня, питание-ориентир и велосипед.

| Решение | Значение |
|---|---|
| Цель по весу | 92 → 88 кг за 4–5 месяцев, очень плавно (−0,15…−0,3 кг/нед), «мягкая рекомпозиция»: сила растёт, жир уходит |
| Данные пользователя | мужчина, 41 год, 178 см, 92 кг, ~20 % жира; поддержание оценено в ~2700–2800 ккал (Миффлин 1830 / Кэтч–Макардл 1960 × 1,45–1,55) |
| Питание | **ориентир**, без отметок «съел»: меню-пример + замены; учёт — только вес |
| Велосипед | по таблице графика, привязан к неделе программы силовых (раздел 3.2) |
| Пятница | ребёнка не забирает: вечер 17:45–19:00 свободен |
| Суббота | в ночь на воскресенье — строка **«Личное время» 23:30–01:00** (нейтрально: репозиторий публичный) |
| Встраивание | вариант 1: раздел внутри текущего приложения, 5 вкладок сохраняются |

Не делаем: дневник питания с продуктами, журнал велосипеда, дневник усталости/сна, Wake Lock, медицинские советы.
Цифры — ориентир, не медицинская рекомендация (при болезнях — показать врачу); это сказано в интерфейсе одной строкой.

## 2. Что не меняется

Расчёты силовых (`src/domain/calculations`, `engine.ts`, `definition.ts`), формат записей тренировок, формат резервной
копии (кроме двух необязательных полей профиля), персональные замены упражнений, офлайн/PWA.

## 3. Ядро: `src/domain/routine/` (чистые функции, без React и IndexedDB)

### 3.1 `template.ts` — шаблон недели

```ts
type RoutineKind = 'work' | 'food' | 'strength' | 'bike' | 'family' | 'rest' | 'sleep' | 'personal'
interface RoutineItem { start: string /* 'HH:MM' */; end?: string; title: string; detail?: string; kind: RoutineKind; meal?: MealId }
type Weekday = 1|2|3|4|5|6|7   // 1 = понедельник
function dayRoutine(weekday: Weekday, ctx: { bike: BikeDay | null; strength: StrengthDay | null }): RoutineItem[]
```

* **Пн/Ср/Пт (силовой день)** — расписание понедельника графика (09:30 подъём … 01:00 сон) + утренняя прогулка
  09:35–09:50. Строка `15:15–16:45` — «Силовая, день N» и список упражнений дня из приложения (`ctx.strength.exercises`;
  нет данных — без списка). Ср: пояснение «становая — центральное упражнение недели»; Пт: «если не влезает в 90 минут —
  режь последнее упражнение».
* **Вт** — расписание вторника, велосипед `15:30–(15:30 + длительность)`, перекус 16:50.
* **Чт** — велосипед по таблице; если в эту неделю его нет — на его месте «Работа», перекус 16:50 убирается.
* **Сб** — велосипед `12:20–(12:20 + длительность)`; окончание считается; душ сразу после; обед 14:15.
  **Вечерний перекус в 21:30** (творог 150 г), **«Личное время» 23:30–01:00**, сон 01:00, подъём в воскресенье 09:30.
* **Вс** — расписание воскресенья графика (прогулка 16:00–17:30, перекус 17:30, ужин 19:30).
* **Пятница-исключение:** вместо «17:50–18:00 выход за ребёнком» и «18:00–19:00 площадка» — «17:45–19:00 Свободно:
  семья, отдых»; ужин 19:00–19:40; вечерний перекус 21:45.

Инвариант: у каждого дня время строк неубывающее, интервалы не пересекаются, последняя строка — сон 01:00.

### 3.2 `bike.ts` — велосипед

Таблица 8 недель (раздел 8 графика): Вт / Чт / Сб в минутах и Z3-блоки (недели 5–7 субботы).

| Неделя программы | П1, П2, Тест | 1…8 | 9 | 10 | 11 | 12 | после программы |
|---|---|---|---|---|---|---|---|
| Неделя велосипеда | 1 | 1…8 | 3 | 5 | 6 | 8 | 3 |

```ts
function bikeWeekFor(programWeek: WeekId | 'done'): 1..8
function bikeDay(bikeWeek, weekday): BikeDay | null   // { minutes, label: 'Z2 40 мин' | 'Z2 55 + 4×2 мин Z3', zone }
```
Текущая неделя программы = неделя активной или следующей тренировки (`AppData.active ?? AppData.next`); программа
пройдена → `'done'`.

### 3.3 `nutrition.ts` — цель дня и меню-ориентир

Тип дня: `strength` (Пн/Ср/Пт), `bike` (Вт, Сб, Чт с велосипедом), `rest` (Вс, Чт без велосипеда).

| Режим | strength | bike | rest |
|---|---|---|---|
| `recomp` (по умолчанию) | 2700 | 2450 | 2200 |
| `maintenance` (вручную, **автоматически в недели 4/8/12 программы**) | 2870 | 2740 | 2480 |

Белок 190 г (rest 185), жиры 72 г, углеводы = (ккал − 4·Б − 9·Ж) / 4. Итог = цель режима + `nutritionAdjustKcal`
(поправка из подсказок, раздел 3.4), но не ниже rest-цели поддержания минус 500 и не выше её плюс 500.

Меню-ориентир: меню графика (maintenance — без изменений). Для `recomp` урезаются **только углеводы ужина и
вечерних перекусов**; предтренировочный обед и приём после тренировки неприкосновенны, кроме хлеба/варенья:

| День | Изменение к графику | Итог ≈ |
|---|---|---|
| strength | после тренировки хлеб 60 → 40 г, варенье 30 → 20 г; ужин гречка 90 → 75 г | 2695 |
| bike (Вт/Чт) | перекус 16:50 — без хлеба и мёда (протеин 30 г + банан); ужин гречка 90 → 50 г, масло 10 → 5 г | 2450 |
| bike (Сб) | то же + вечерний перекус творог 150 г в 21:30 | 2400 |
| rest (Вс) | перекус: орехи 20 → 10 г, без хлеба; ужин картофель 350 → 250 г; «при голоде» кефир 300 мл | 2120 (+150) |
| Чт без велосипеда | меню bike без перекуса 16:50 | 2235 |

Суммы меню должны совпадать с целью дня в пределах ±5 % (тест). При поправке `nutritionAdjustKcal` меню не
пересчитывается — показывается строка «к меню: ±N ккал углеводами (рис/хлеб)».
Под меню — «Замены» из раздела 9 графика (белковая и углеводная основа, три завтрака).

### 3.4 `trend.ts` — подсказки по весу и силе

```ts
interface TrendAdvice { kind: 'need-data' | 'ok' | 'too-fast' | 'stalled' | 'strength-guard'; deltaKcal: number; text: string }
function weightTrend(bodyweights, today): { avg7: number|null; prevAvg7: number|null; ratePerWeek: number|null }
function advice(bodyweights, workouts, today): TrendAdvice
```
* Меньше 2 недель записей веса или нет записей за последние 7 дней → `need-data` («внесите вес, чтобы следить за темпом»).
* Темп = avg7 − prevAvg7 (кг/нед). Быстрее −0,4 → `too-fast`, +150 ккал.
* Средний вес не снизился (|Δ| < 0,1 кг/нед) **3 недели подряд** → `stalled`, −150 ккал (в велодни и rest).
* **Предохранитель силы** (приоритетнее остальных): по жиму лёжа и приседу — оценочный 1ПМ лучшего подхода недели
  (`setE1rm`) две завершённые недели подряд ниже лучшего значения двух предыдущих недель более чем на 2,5 % →
  `strength-guard`, +200 ккал в силовые дни.
* Иначе `ok` («темп −0,2 кг/нед — норма, ничего не меняем»).
* В недели 4/8/12 подсказки `stalled` не даются (поддержание).

Подсказка применяется **только по нажатию** «Применить»: `nutritionAdjustKcal += deltaKcal` + запись в журнал изменений.

## 4. Хранение

`ProfileRow` — два необязательных поля: `nutritionMode?: 'recomp' | 'maintenance'` (нет → `recomp`),
`nutritionAdjustKcal?: number` (нет → 0). `SCHEMA_VERSION` не меняется; валидатор резервной копии не требует полей.

## 5. Интерфейс

**«Сегодня»** (сверху вниз):
1. «Сейчас / далее» — текущий пункт крупно, следующий со временем; обновление раз в минуту в отдельном компоненте.
2. Лента дня — строки «время · что», прошедшие приглушены, ближайшие 6 строк, «весь день» по нажатию.
3. Цель дня — «Силовой день · 2700 ккал · Б 190 / Ж 72 / У ~320», меню раскрывается.
4. Карточка тренировки: силовая (как сейчас, «Начать тренировку») или велосипед («Z2 40 мин · разговорный темп»).
5. Вес (существующая карточка) + подсказка тренда с кнопками «Применить» / «Не сейчас».

**«План» → переключатель «Тренировки | Неделя».** «Неделя»: велосипед текущей недели («неделя велосипеда 3 из 8»,
таблица Вт/Чт/Сб) и 7 строк дней («Пн · Силовая, день 1 · 2700 ккал»), по нажатию — расписание и меню.

**Настройки:** «Режим питания: мягкая рекомпозиция / поддержание», «Поправка: +N ккал [Сбросить]», строка
«Недели 4/8/12 — поддержание автоматически», строка-оговорка «ориентир, не медицинская рекомендация».

Оформление — существующие токены и компоненты (тёмная/светлая темы, 44 px зоны нажатия, контраст ≥ 4,5:1).
